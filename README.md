# Crochet Haven Website

Crochet Haven is a handmade crochet products website developed using PHP and MySQL. The website allows users to browse crochet products, place orders, manage profiles, and submit reviews.

## Features

- User Registration and Login
- Product Listing and Product Details
- Add to Cart and Checkout System
- Order Placement and Order Success Page
- User Profile Management
- Product Reviews System
- Contact Form
- Admin Product Management
- Responsive Website Design

## Project Pages

- index.php – Home page
- login.php – User login
- register.php – User registration
- products.php – Product listing
- checkout.php – Checkout process
- place_order.php – Order placement
- order_success.php – Order confirmation
- my_orders.php – User order history
- profile.php – User profile
- update_profile.php – Profile update
- add_review.php – Add product review
- get_reviews.php – Fetch reviews
- contact.php – Contact page
- submit_contact.php – Contact form submission
- sustainability.php – Sustainability information page
- admin.php – Admin panel

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Database Setup

Import the `database.sql` file into MySQL before running the project.
